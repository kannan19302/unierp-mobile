# Mobile Parity Exemptions

The following modules have cleared the 200 features threshold in the API and Web UI layers but are explicitly exempted from having a Flutter mobile implementation in this cycle due to time constraints and focus on backend/web parity first:

1. `api-platform`
2. `ext-gateway`
3. `devops`
4. `notifications`
5. `outbox`
6. `pwa`
7. `saved-views`
8. `fixed-assets`
9. `subscriptions`
10. `localization`
11. `reporting`
12. `people`
13. `service-management`
14. `blockchain`
15. `drive`
16. `search`

These modules will need mobile implementations in a future track to fully comply with layer 6 of the MULTI_CLIENT_MASTER_PLAN.
